# 📦 Inventory Management System

A Python-based Inventory Management System built using **Tkinter and SQLite**. This desktop application helps manage products, monitor stock levels, maintain supplier records, track stock movements, and generate inventory reports.

## 🚀 Features

- **Dashboard:** View important inventory statistics.
- **Product Management:** Add, edit, delete, and search products.
- **Advanced Product Filtering:** Filter products by category and stock status, and sort inventory.
- **Stock Management:** Record stock-in and stock-out transactions.
- **Stock Status Indicators:** Identify in-stock, low-stock, and out-of-stock products.
- **Supplier Management:** Maintain supplier information.
- **Transaction History:** Search and filter stock transactions.
- **Reports & Analytics:** View inventory summaries and stock analysis.
- **Data Visualization:** Display inventory analytics using charts.
- **Excel Export:** Export inventory reports to Excel.
- **PDF Export:** Generate PDF inventory reports.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|

| SQLite | Database management |

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/AbBa-07/Inventory_Management_System.git
```

### 2. Navigate to the project directory

```bash
cd Inventory_Management_System
```

### 3. Install the required libraries

```bash
pip install matplotlib openpyxl reportlab
```

Tkinter and SQLite are generally included with standard Python installations.

### 4. Run the application

```bash
python main.py
```

The application initializes its SQLite database when started.
